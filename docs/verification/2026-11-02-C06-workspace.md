# C06 — bounded layout model and persistence

2026-11-02. Layout model and persistence bridge implemented; visual integration is
C07. The existing desktop still builds with the new layout-only IPC commands.

The immutable model validates nested split/tab trees, membership, active/focused
views, duplicate interactive resources, finite weights and size limits. It caps
64 views, 32 groups, depth 12 and 256 KiB JSON. Move, split, hide, collapse and
maximize change resource references only. Cancelled or invalid gestures keep the
original object. Unsupported panel kinds remain unavailable and restore cannot
launch a process.

The desktop owns window/PID/Windows creation-time identity; the WebView supplies
only project/workspace selectors, revision and layout. One reserved background
operation performs FS03 CAS reads/writes/releases. Conflicts or another owner
preserve the saved data. The frontend coalesces local edits into one latest layout,
never queues multiple writes, bounds flushes and disables automatic writes after
conflict, uncertainty or timeout. A late acknowledgement does not re-arm saving.

Six focused model/persistence tests pass. The desktop custom-protocol cargo check
passes. Actual workspace rendering, save/restart and explicit stale-owner recovery
are verified with the C07 integration rather than an extra duplicate app run here.

The subsequent explicit ownership recovery passes five focused Windows/SQLite
tests. The native probe distinguishes an exact live owner, a signaled old process,
missing PID, reused PID and unknown/access-denied identity. Only proof of the old
identity's death permits an exact record/owner/revision CAS. In one transaction the
DAO clears the old owner, assigns the replacement and increments the revision;
layout and timestamps remain unchanged. The schema's generic ownership guard stays
enabled. Replayed proofs and future schemas are refused. Desktop IPC obtains the
record and proof internally and exposes an explicit recovery action; no PID/proof
is accepted from the WebView. The desktop build passes with these commands.
