## Global Constraints

- Branches: `main` and `develop` only; work on `develop` or a short branch from it. Never push to `main`, never set a version or a tag by hand.
- No UI framework, no runtime dependency in the CSS or `ts/ui`. `ts/shell` may import `@tauri-apps/api`.
- Local Windows fonts only: `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif` (text), `Bahnschrift, "Segoe UI Variable Display", "Segoe UI", sans-serif` (ONI, display), `"Cascadia Mono", "Cascadia Code", Consolas, monospace` (code, paths, IDs, key caps). Nothing is downloaded.
- Every class is prefixed `im-`, every custom property `--im-`. Root attributes: `data-im-app` (`shinatama|xiox|mukade|muro|daodan`), `data-im-look` (`smooth|oni`), `data-im-theme` (`dark|light`). The root class `im-glass` is set only in the desktop app; without it every surface is opaque.
- Accent, from the app's hue H (xiox 75, shinatama 355, mukade 300, muro 170, daodan 235): on dark `oklch(0.82 0.12 H)`, text on it `oklch(0.20 0.04 H)`, highlighted `oklch(0.90 0.08 H)`; on light `oklch(0.47 0.13 H)` with `#FFFFFF` on the fill.
- Measures (Smooth / ONI, px): title bar 46/38, control and field 32/28, small control 24/22, list row 32/28, two-line row 44/40, table row 36/32, panel header 42/40, footer 30/26; sidebar 232, rail 56, inspector 300 to 360, content 420 or more. Radius Smooth 4/6/10; ONI 0 with cuts 6/8/14. Spacing 4, 8, 12, 16, 24. Motion 120ms and 180ms, `cubic-bezier(0.16, 1, 0.3, 1)`.
- Breakpoints on the window's own width (container queries): 1000, 850, 620. Minimum 500.
- Text contrast 4.5:1 or more on the opaque colour of its surface, disabled text included.
- No `showModal()`. No hand cursor. Chrome text is not selectable; content is.
- Glass values are Shinatama's measured ones (`docs/design-system/desktop-shell.md` section 1.3).
- Commit messages in English, conventional prefix, ending with the attribution line the session gives.

## Review Focus

1. **Zoom 200% in a 500px window** (effective width 250px): no horizontal scroll, the primary action stays reachable. Test in Task 3.
2. **Windows drops the material, or forced colours are on**: without `im-glass` every text token still passes 4.5:1, and in `forced-colors` the focus ring and control borders are still drawn. Tests in Tasks 2 and 4.
3. **A stored look, theme or app value that is unknown or corrupt** (`look=modules`, empty string): falls back to `smooth` and the Windows theme without throwing. Test in Task 9.
4. **Two layers open at once** (a menu inside a dialog; the palette asked for while a dialog is open): Escape closes only the top one, focus returns to the right control, the palette does not open over a dialog. Test in Task 7.
5. **Long labels and IME**: a 60-character button, tab or row label ends with an ellipsis and keeps a tooltip without changing the control's height; Enter during IME composition does not run the primary action. Tests in Tasks 4 and 5.

  ```ts
  export type Command = { id: string; title: string; keys?: string; group?: string; when?: () => boolean; run: () => void | Promise<void> };
  export type Registry = {
    register(command: Command): () => void;          // returns unregister; a duplicate id throws
    list(): Command[];                                // only commands whose when() is not false
    get(id: string): Command | undefined;
    match(event: KeyEventLike): Command | undefined;
    attach(target: EventTarget): () => void;          // keydown listener; returns detach
  };
  export type KeyEventLike = { key: string; ctrlKey: boolean; shiftKey: boolean; altKey: boolean; metaKey: boolean; isComposing?: boolean; keyCode?: number; target?: unknown };
  export function createRegistry(): Registry;

  export function isTextTarget(target: unknown): boolean; // input, textarea, select, contenteditable
  ```
