# Shinatama widget portraits — generated friendly expressions

2026-11-03. Created with the built-in `image_gen.imagegen` tool (imagegen skill), using the canonical Oni portrait as identity reference and a first high-resolution neutral redraw as the expression-edit target. Transparent PNG alpha is preserved without post-processing. No CLI/API fallback was used.

The neutral redraw `shinatama-neutral-v1.png` is retained as a generation reference. The popup uses only the three friendly expressions below. It starts with smile, then chooses randomly between the other two on each new notice; refreshing the same notice keeps its portrait.

## Saved assets and exact final prompts

### smile

- Project asset: [shinatama-smile-v1.png](shinatama-smile-v1.png).
- Image 1 (edit target): [neutral redraw](shinatama-neutral-v1.png).
- Image 2 (identity reference): [canonical Oni portrait](../branding/references/shinatama-oni-original.png).
- Output: transparent PNG, preserved as returned by the built-in tool.

```text

Preserve her pink fluffy bob and outward tufts, curled forelock, facial identity and proportions, cybernetic facial details and eye design, white uniform with blue tie, head angle looking slightly right, shoulder position, linework, shading, framing, scale and silhouette. Change ONLY the facial expression described below. She must look clearly approachable, kind, friendly and warm, not stern, angry, worried or sad. Do not redesign her or change the costume; no headset, no chibi proportions, no purple hair. Same clean polished anime game art. One head-and-upper-chest portrait, complete hair silhouette and shoulders inside the canvas with modest margins. Genuine transparent alpha background, clean cutout edges. No background, panel, frame, glow, text, watermark, extra characters or props.
Expression: A gentle, naturally friendly closed-mouth smile. Relax the eyebrows completely, soften the gaze, lift the mouth corners visibly, add a little warmth to the cheeks. Calm and welcoming; the smile should still read at thumbnail size.
```
