## Surprises / notes

- Mock interaction: Pi's compaction request quotes `H27-TOOLS` from the conversation, so the shared
  mock answered it `H27-NOTOOL: no read or shell tool offered (tools: )`, which became the stored summary.
  Fixed in a local copy `verify/H27/pi/server.local.mjs` (diff: `verify/H27/pi/server.local.diff`: a
  tool-less request matching the summary regex gets `H27-SUMMARY` before the HANG/TOOLS checks). The
  shared `mock/server.mjs` is unchanged by me; the copy is rebased on its 16:37 version.
- The brief's T3 prompt contains "compaction", which matches the mock's summary regex, so T3's reply is
  the `<summary>H27-SUMMARY…` text (stored as a normal assistant message). Applies to every harness.
- `keepRecentTokens` decides the boundary with chars/4 estimates. With `1`, the cut lands on the T2
  assistant ("split turn"): two summary requests and a summary containing `**Turn Context (split turn):**`
  (`probe/rpc-compact-splitturn.stdout.jsonl`, `probe/capture-probe.jsonl` n4–n5). `10` cuts at the T2 user.
- `tokensBefore` is 120: the mock's reported usage, not an estimate.
- Startup was fast here (0.4–1.0 s per print-mode turn), unlike PI11's slow `--help`.
